# PASSO-SEGURO

O **Passo Seguro** é um aplicativo de apoio ao autocuidado e ao acompanhamento de pessoas com diabetes, com foco na saúde dos pés.

A plataforma oferece recursos para registrar avaliações, acompanhar informações relacionadas aos cuidados com os pés, consultar o histórico de registros e acessar orientações educativas para o cuidado diário.

O objetivo é facilitar o acompanhamento das condições dos pés, estimular o autocuidado e apoiar a comunicação entre pacientes e profissionais de saúde, contribuindo para a prevenção de complicações.

O aplicativo possui áreas destinadas aos pacientes e aos profissionais de saúde, com funcionalidades de cadastro, perfil, avaliações, histórico e orientações educativas.

**Tecnologias:** HTML, CSS, JavaScript e integração com serviços de banco de dados e autenticação.

**Importante:** O Passo Seguro é uma ferramenta de apoio ao autocuidado e não substitui avaliação, diagnóstico ou acompanhamento realizado por profissionais de saúde.
